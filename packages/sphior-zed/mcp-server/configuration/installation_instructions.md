SPHIOR CODE scans your workspace for hard-coded secrets, insecure code patterns mapped to CWE and taint flows, and gives the agent fix guidance for each finding.

It works with no account: without an API key it runs locally with the bundled deterministic engine, and your source code never leaves your machine.

To also reach the repositories you connected to SPHIOR on GitHub, add an API key from https://sphior.com/app?settings=api.
